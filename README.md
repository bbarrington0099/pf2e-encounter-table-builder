# PF2e Encounter Table Builder

A Foundry VTT module for Pathfinder 2e that helps Game Masters quickly build XP-balanced encounter roll tables by dragging actors into structured encounter rows, automatically calculating XP budgets and difficulty, and generating a native Foundry RollTable.

## Overview

The PF2e Encounter Table Builder is a visual tool that lets you:

* Build encounter “rows” using drag-and-drop actors
* Automatically calculate XP budgets based on party size and level
* Evaluate encounter difficulty using PF2e encounter math
* Assign weights to encounters for roll tables
* Generate a native Foundry RollTable with one click
* Persist party level/size between sessions


## Features

### Encounter Construction UI

* Drag & drop Actors directly into encounter rows
* Increase/decrease creature quantity per encounter
* Expand/collapse encounter groups
* Remove individual actors or entire rows

### PF2e XP Budget Integration

Automatically calculates encounter difficulty using PF2e encounter building rules:

* Trivial
* Low
* Moderate
* Severe
* Extreme

XP budgets scale dynamically based on:

* Party level
* Party size
